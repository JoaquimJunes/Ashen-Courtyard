# Old hop dodge — removed

The user requested removal of the old 0.60 m hop and its comparison switch.
Its ability definition, execution path, setup flag and unused timing aliases
have been deleted. It is no longer available in any level.

All hosts now share the adaptive forward dive and grounded side/back reference
rolls. See [current behavior and validation](docs/UNIFIED_DODGE.md),
[forward dive](DODGE_PREVIEW.md) and [ground rolls](docs/GROUND_ROLLS.md).

Older screenshots and validation reports are historical evidence, not current
runtime behavior. Ask the user before developing anything further.
